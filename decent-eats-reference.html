Overview

Decent Eats is a personal recipe management web app. It replaces the Blogger site at gomezcookery.blogspot.com with a structured, searchable database of recipes, ingredient cross-referencing, and cooking notes.

It runs as a single HTML file hosted on Vercel, connected to a Supabase PostgreSQL database. No frameworks, no build step — just one file that works in any browser on desktop, iPhone, and iPad.

How it fits together

  1. The app is a single file: index.html, stored in a GitHub repository.
  2. Vercel watches that repository. Every time you push a change to the main branch, Vercel automatically deploys the updated file within about 30 seconds.
  3. The app talks directly to Supabase via its REST API using your anon key. All recipe data lives in Supabase — not in the file itself.
  4. Because the data is in Supabase (cloud), it is accessible from any device that opens the app URL.

Deployment Workflow

How to update the app after making changes to index.html (standardized on the GitHub website approach across all apps):

1
Get the updated fileDownload the updated file(s) from Claude.
2
Open the GitHub repoGo to github.com/danielgomez909/recipe-app
3
Upload or edit the fileClick the file, then the pencil icon to edit, or drag-and-drop to upload a replacement.
4
Commit changesAdd a short commit message and click "Commit changes".
5
Vercel auto-deploysWithin ~30 seconds, Vercel detects the push and deploys the new version. Visit project-a7lbt.vercel.app to confirm.

To make a database schema change (add a column, new table, etc.), go to Supabase → SQL Editor, run your SQL, then update the app code if needed and deploy.

Installing on iPhone / iPad

  1. Open project-a7lbt.vercel.app in Safari
  2. Tap the Share button (box with arrow)
  3. Tap Add to Home Screen
  4. The app appears as an icon and opens full-screen like a native app

Bulk Import History

Two one-time bulk imports were performed to migrate existing recipe data into Decent Eats as draft recipes:

Blog migration (116 recipes)

Source: gomezcookery.blogspot.com. Saved as 3 HTML pages (Decent_Eats_A/B/C.html) covering the full blog archive at expanded posts-per-page. Parsed using a tiered approach: modern posts with consistent Source/Notes/Serves/Ingredients/Program/Variations/Log/Tags/Version field structure parsed cleanly into proper fields; older free-form posts fell back to dash-bullet and numbered-list detection. All 116 imported as [DRAFT] recipes with the full original text preserved in raw_import_text and a link to the original post in import_source_url. Source HTML files are stored in the GitHub repo (excluded from Vercel deployment via .vercelignore) for reference.

Trello migration (361 cards)

Source: a Trello board used as a recipe queue ("Interested", "Queue", "Retired", "Published", "Done", "Template", "Editing" lists). Exported to Excel (trello_recipes_open_cards.xlsx) and imported in full regardless of list status. URLs were extracted from the Source URL column when present, or detected via regex in the card name or description when not. Fuzzy title matching (≥80% similarity) against the 116 blog drafts flagged 114 likely duplicates — these were still imported but with a duplicate warning prepended to their raw_import_text for manual review. The source Excel file is stored in the GitHub repo (excluded from Vercel deployment via .vercelignore) for reference.

Total draft recipes pending cleanup after both imports: 477. Use the Draft Recipes tab to review each one — the cleanup form shows the original raw text and source link alongside the normal recipe fields. Saving removes the [DRAFT] prefix and draft status; the Delete Draft button permanently removes a draft you've decided not to build.
